廢(污)水生物處理程序｜測驗網站 v1.0
=====================================

題庫來源：生物處理.md
題庫題數：430 題
每回題數：40 題（剩餘題數不足 40 題時，以剩餘題數出題）

主要功能
1. 430 題自動轉為網站題庫。
2. 題目依內容分成 8 大主題，每回原則上每類抽 5 題。
3. 錯題保留並提高下一回合再次抽到的機會。
4. 答對題目加入「已掌握」，之後不再出題。
5. 交卷後計算分數，逐題顯示答案：答對綠色、答錯紅色、未作答黃色。
6. 自動統計各主題正確率，列出弱項與加強方向。
7. 使用瀏覽器 localStorage 保存學習進度；支援 JSON 匯出／匯入備份。
8. 作答中重新整理頁面可繼續本回測驗。

8 大主題與目前題數
- MBR 薄膜生物反應器：22 題
- 污泥處理與處置：14 題
- 脫氮除磷與營養鹽：49 題
- 附著生長與生物膜：47 題
- SBR／氧化渠與改良活性污泥法：50 題
- 厭氧生物處理：55 題
- 活性污泥與操作控制：102 題
- 微生物與生物處理基礎：91 題

如何直接測試
------------
雙擊 index.html 即可開啟。建議使用 Chrome / Edge。

GitHub Pages 發布
----------------
1. 建立一個新的 GitHub repository，例如 bio-treatment-quiz。
2. 將本資料夾中的 index.html、style.css、app.js、questions.js 上傳到 repository 根目錄。
3. GitHub repository → Settings → Pages。
4. Build and deployment 選 Deploy from a branch。
5. Branch 選 main、資料夾選 /(root)，按 Save。
6. 等 GitHub Pages 顯示網站網址後即可分享。

重要：學習紀錄保存方式
----------------------
本版為純靜態網站，學習紀錄只存在「使用者目前裝置＋目前瀏覽器」的 localStorage。
換電腦、無痕模式、清除瀏覽資料，或換瀏覽器時，原紀錄不會自動同步。
建議利用網站上的「匯出學習紀錄」定期備份；換裝置時可再「匯入學習紀錄」。
如需要學生姓名、跨裝置同步、教師後台、Google Sheet 成績紀錄，可再接 Google Apps Script／Google Sheet 後台。
